# integrative-project
In simple words this project is a library management system developed in C++11 using Object-Oriented Programming principles

Bassically the program allows users to: view the library catalog, register students, search for books, borrow books
and view active loans through an interactive menu.
The library includes a collection of preloaded books while students are registered during program execution
The project demonstrates important OOP concepts such as inheritance, polymorphism, composition, and the Rule of Zero
